### What I've built

| Project | What it does |
|---|---|
| **AEGIS: LLM attack-path agents** · [paper (arXiv)](https://arxiv.org/abs/2601.22720) | Multi-agent system for the Singapore Armed Forces that discovers and validates exploit chains with LLMs. Runs 100+ step attack paths. 
| **AI-safety classifier** · [model (Hugging Face)](https://huggingface.co/alexc09/MiniLM-L12-H384-uncased_Nvidia-Aegis-AI-Safety) | Open-source harmful-content classifier, 220,000+ downloads.
| **Aggregate** · [site](https://aggregate.usehovr.app) | Startup on a $25K AWS grant: browser agents collecting from 50+ sources daily (~98% success) into personalized digests. |
| **Straits Cipher: historical archives RAG** · [demo video](https://youtu.be/I2_FPGli96Y) · [repo](https://github.com/kiritowu/ai-history-hackathon) | Citation-backed Q&A over ~7,000 colonial archive pages: OCR + hybrid-search RAG, ingested in ~30 min at $0.82 per 1,000 pages with parallel vLLM on burstable GPUs. Team of 3. |
